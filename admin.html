🔄 Workflow Avify

Paiement CCP → confirmation manuelle → abonnement actif → rappels → blocage à expiration → réactivation en 1 clic.

① Le client paie via BaridiMob / CCP.
② Vous confirmez le paiement depuis l'administration.
③ La date d'expiration est calculée automatiquement et les cartes du client peuvent être réactivées.
④ Le contrôle d'expiration peut être synchronisé via cron-job.org pour un blocage même hors connexion.
